# Phase 4 — Trip Experience, Sync & Stats

**Codename:** Afterglow  
**Goal:** End-to-end “what happened on this drive” + offline sync + first dopamine.  
**Depends on:** Phase 3  
**Unlocks:** Phase 5–6  

---

## Scope
1. Local trip processor: route polyline, events, metrics, provisional quality
2. Screens: Processing, Summary, Timeline, Speed graph, Elevation, Replay
3. **Max gamify** on Summary (score count-up, XP stub bar, seal stamp)
4. Trips list + trip detail
5. Profile stats + personal records (local)
6. Sync engine: WorkManager + idempotent `POST /v1/trips*` 
7. Backend trip ingest + process worker (integrity stub OK)
8. Exploration geohash cells v1 unlock toast (post-drive only)

## Out of scope
Full seasonal boards, friends, garage, workshops

## Exit criteria
- [ ] Offline end → later sync once (no dupes)
- [ ] Replay syncs map + graph
- [ ] Summary feels “adventure complete”
- [ ] Server stores trip for user
- [ ] BUILD-LOG entry

## S1 Definition of Done (partial)
Pipeline through summary + sync solid before heavy S2.
