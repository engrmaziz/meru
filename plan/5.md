# Phase 5 — Score, XP, Achievements & Challenges

**Codename:** Engine of Want  
**Goal:** Progression loop that makes users want the next drive.  
**Depends on:** Phase 4  
**Unlocks:** Phase 6  
**Status:** Complete (2026-09-15)

---

## Scope
1. Server scoring modules: Driving Quality, Exploration, Activity (+ stubs for rest)
2. Separate Driver Rating vs Adventure Score (DEC philosophy)
3. Configurable weights table (not hard-coded in APK)
4. XP ledger, levels, titles
5. Achievements engine + rarity frames UI (**animate unlocks**)
6. Challenges: daily/weekly CRUD + progress
7. Home dashboard: XP bar, scores, next challenge, streak — **max motion**
8. Notifications opt-in: level-up, challenge, streak (no mid-drive spam)
9. Integrity score gates competitive eligibility (basic)

## Out of scope
Full 4-level boards UI (Phase 6), social graph, seasons end ceremony polish optional here

## Exit criteria
- [x] Trip finalize awards XP/achievements server-side
- [x] Client shows provisional then refreshes final
- [x] Spoofed client score ignored
- [x] Home feels like a game hub
- [x] BUILD-LOG entry
