# Phase 3 — Live Drive UI, Map & Sensors

**Codename:** Cockpit  
**Goal:** Beautiful, calm live drive experience + calibration + motion metrics.  
**Depends on:** Phase 2  
**Unlocks:** Phase 4  

---

## Scope
1. Stitch → Compose: Drive Minimal / Detailed / Performance / HUD
2. MapLibre live polyline + bearing (DEC-008)
3. Phone calibration flow + recalibrate in settings
4. Accelerometer/gyro pipeline → accel, brake, cornering, G-gauge
5. Weak GPS / permission-lost overlays
6. Confirm End Drive sheet
7. Gamify: **none mid-drive** (skill enforced); glanceable only
8. Reduce-motion respectful transitions into Drive

## Out of scope
Trip summary polish, replay, leaderboards, server upload

## Exit criteria
- [x] All 4 dashboard modes usable (Minimal / Detailed / Performance / HUD)
- [x] Map tracks route during drive (MapLibre polyline)
- [x] Calibration changes sensor axes meaningfully (MotionMath + CalibrationStore)
- [x] Night contrast via Meru void/teal tokens
- [x] BUILD-LOG entry

## Design
Anti-slop skill + Stitch MCP mandatory for Drive screens (pick calmest variants).
