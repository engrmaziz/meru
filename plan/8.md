# Phase 8 — Workshop Discovery & Booking

**Codename:** Bay  
**Goal:** Find brand-fit workshops and book a real slot.  
**Depends on:** Phase 7 (vehicle + history share)  
**Unlocks:** Phase 9  

---

## Scope
1. Workshop entity + KYC pending state
2. Brand specialization (specialist / multi / general)
3. Services + parts catalog (shared taxonomy)
4. Hours + bays + slot generator
5. Customer discovery: search/filter/rank (brand fit → distance → rating)
6. Workshop profile (Stitch → Compose) + MapLibre pins
7. Booking flow: vehicle → services → slot hold (Redis) → share scope → confirm
8. My Bookings list + status tracker stub
9. Notifications: booking confirmed / reminder
10. Seed 3–5 fake workshops for pilot city

## Out of scope
Invoice builder, staff web portal polish, payments gateway

## Exit criteria
- [ ] Audi car ranks Audi specialists higher
- [ ] Double-book impossible under concurrency test
- [ ] Hold expiry frees slot
- [ ] History share attached to booking
- [ ] BUILD-LOG entry

## Budget
Workshop **web** staff UI can start minimal in Phase 9; this phase focuses customer Android + API.
