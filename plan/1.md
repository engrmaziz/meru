# Phase 1 — Foundation & Design System

**Codename:** Bedrock  
**Goal:** Empty app that looks like Meru, navigates, authenticates (dev), and is ready for the driving engine.  
**Depends on:** —  
**Unlocks:** Phase 2  
**Docs:** `docs/decisions.md`, `docs/flow.md`, `docs/AI-AGENT-BUILD-BIBLE.md` §0–10, ANNEX-E  
**Tools:** Ponytail · Context7 · Stitch MCP · anti-slop skill  

---

## Scope
1. Android project (Kotlin, Compose, Hilt, Navigation, Room stub, DataStore)
2. Design tokens + core Compose components (theme Meru: void/teal)
3. Stitch: Welcome, Home shell, Drive Ready shell (3 screens min)
4. Nav shell: Home | Drive | Trips | Garage | More (stubs OK)
5. Auth: email + Google (dev backend or Firebase Auth if cheaper for MVP login only)
6. Backend hello: NestJS health + `/v1/auth` stub + Postgres docker
7. Feature flags client stub
8. Crashlytics stub (optional Firebase Spark)
9. CI: build Android debug + backend test green
10. Append `BUILD-LOG.md`; DEC updates if stack tweaks

## Out of scope
GPS, trips, scores, workshops, real maps, billing

## Exit criteria
- [x] App installs; Welcome → Auth → Home shell (source ready; needs Android Studio/SDK to install on device)
- [x] Meru branding on Welcome
- [x] Theme tokens centralized
- [x] Backend `/health` 200 locally
- [x] BUILD-LOG entry for Phase 1

## Budget notes
Single docker-compose for Postgres(+Redis optional). No paid maps yet.
